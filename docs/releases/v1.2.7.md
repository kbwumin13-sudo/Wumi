# Wumi 1.2.7：修复搜索自动刷新频闪

相对 1.2.6，本补丁修复内置觅迹在索引持续更新时反复变暗、动作短暂不可用和预览清空重载的问题。内置觅迹继续为 1.3。

## 自动更新保留当前搜索

同一查询的后台刷新保留已提交结果、选择和预览，完成后原子更新。前台搜索状态与计时不会因普通索引通知反复重置。正文新增、关键词移除和摘要变化仍会更新结果；既有通知合并、两秒限频和隐藏时停止工作继续保留。

## 旧请求与文件动作仍受保护

换词、筛选、排序、目录或根路径变化仍立即使旧请求失效。A→B→A 不接受最初 A 的旧回调，后台执行 ticket 单独取消和校验。根路径身份与文件 ID、路径、inode 等检查保留；常规文件在同路径被替换后，旧行不能误操作新的 inode。检查只读 metadata，不枚举包目录，不隐式下载云占位正文。离线和占位文件沿用各动作的既有能力。

## 验证与数据保全

定向模型回归先复现变暗、预览清空和动作闪断，再验证修复；同查询三次目录事件应保持结果、选择、预览与动作可用。正文新增/移除在全部和内容范围下更新，另覆盖请求及根路径 A→B→A、替换、删除、隐藏和关闭释放。最终 Debug/Release 模型、原生窗口时序、签名与打包结果由对应交付记录提供。

已完成 Debug 实际嵌入模型 166/166，以及相关后端/宿主配置 18 项检查，均无失败。Release 与原生窗口、签名、DMG 的最终状态以对应交付记录为准。

本补丁不改 schema、索引写入、提取、调度或扫描范围，不重建索引。日用替换保留索引整组、根/排除配置、偏好、会话与使用历史，并分别记录停写替换和重启后的正常更新。没有把临时 QA 查询延迟或小夹具数据作为生产性能结论。

## 下载与校验

适用于 macOS 15+、Apple Silicon。下载 [Wumi-1.2.7-arm64.dmg](https://github.com/kbwumin13-sudo/Wumi/releases/download/v1.2.7/Wumi-1.2.7-arm64.dmg) 和 [SHA256SUMS.txt](https://github.com/kbwumin13-sudo/Wumi/releases/download/v1.2.7/SHA256SUMS.txt) 到同一目录，运行：

    shasum -a 256 -c SHA256SUMS.txt

公开包沿用既有 ad-hoc 签名，未经过 Apple 公证；本机更新保留原本地签名身份。[Latest Release](https://github.com/kbwumin13-sudo/Wumi/releases/latest) · [安装说明](../../README.md#上手)。
