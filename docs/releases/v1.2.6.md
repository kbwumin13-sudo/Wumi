# Wumi 1.2.6：内置觅迹 1.3 搜索同步

相对日用 1.2.5，本轮更新内置搜索的正文候选、结果有效性和呈现方式。PDF 页码、代码行定位、预览三态与网格是已有能力，本轮继续保留。

## 改进

- 宽泛正文查询过去容易先填满返回列表，较早入库的有效正文可能被截掉。本轮在有限候选与解压预算内继续验证、排序，保护强文件名命中，让强正文结果合理参与合并；普通名称与强正文重叠时也能提升且不重复。触及预算会标为部分检索，提示缩小范围。
- 切换查询、类型、位置、排序或当前目录后，旧结果及延后的菜单、媒体回调不能继续操作文件。当前请求已返回的有效首批结果仍可使用，不必等待全部正文完成。
- 筛选条件可单独移除，重置保留搜索词和视图偏好。短位置显示父目录与磁盘；离线、原文件不可用、提取失败和部分内容分开提示。搜索默认跟随系统外观，可选深色毛玻璃；首批与完成耗时分别显示。窄预览在布局完成或尺寸变化后重新定位到 PDF 命中选区。

## 成本与保全

相关度正文检索使用请求内预算：候选最多 4,000，候选阶段最多解压 48 MiB，含所选摘要最多 64 MiB，总期限 2 秒。预算覆盖的是这一读取阶段，不代表整个应用在任何数据规模下均于 2 秒内完成。为减少截断，正文可能比旧版继续多读候选；没有据此宣称全面提速或整体内存下降。

沿用 Wumi 的唯一索引宿主、名称映射缓存、双只读查询连接、可见性门控、通知合并、关窗释放，以及现有扫描和提取调度。本轮不迁移 schema、不改变正文存储格式、不重建索引，也不启用暂停的语义实验。升级保全检查单列现有索引、根与排除目录、配置、会话和使用历史；停止写入后的替换检查与重启后的正常索引更新分开记录。

## 本轮本地验证

- 主包：240 项，4 项条件跳过，无失败。
- 内置 Core：140 项，1 项条件跳过，无失败。其中有界候选/强正文/摘要期限/真实取消质量回归 9 项。
- 编码、PDF 页码与质量定向回归：24 项，包含旧正文编码与 pageRanges/未知字段的 JSONDecoder 回退。
- 实际嵌入模型：119 项，覆盖首批结果可操作、旧回调拦截、当前目录、筛选重置、离线、内容失效、配置交接及正常关闭释放；新增 PDF 初次/变窄定位和拆卸释放检查。
- 隔离窗口、正式 Release、签名和 DMG 的最终状态随 Release 交付记录提供。

上述搜索质量数据来自本项目隔离夹具，不是生产全盘排名评测，也不借用独立 Miji 的合成性能数字。macOS 15 实机、另一台 Mac 首次 Gatekeeper 授权和长期生产资源表现未在本轮验证。

## 下载与安装

适用于 macOS 15+、Apple Silicon（arm64）。公开 DMG 沿用项目的 ad-hoc 签名流程，未经过 Apple 公证；本机替换沿用已有本地签名与授权保全流程。

[Wumi-1.2.6-arm64.dmg](https://github.com/kbwumin13-sudo/Wumi/releases/download/v1.2.6/Wumi-1.2.6-arm64.dmg) · [Release 与 SHA-256](https://github.com/kbwumin13-sudo/Wumi/releases/tag/v1.2.6)

下载同页校验文件，在下载目录运行 shasum -a 256 -c SHA256SUMS.txt。打开 DMG，将 Wumi.app 拖到 Applications。若 Gatekeeper 拦截，核对来源后按系统“隐私与安全性”提示处理，参阅 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。
