# Wumi 1.2.6：内置觅迹 1.3 搜索同步

相对日用 1.2.5，本轮更新内置搜索的正文候选、结果有效性和呈现方式。PDF 页码、代码行定位、预览三态与网格是已有能力，本轮继续保留。

## 正文候选与排序

宽泛正文查询在有限候选与解压预算内继续验证、排序，减少较早入库的有效正文被返回上限截断的机会。保护强文件名命中，让强正文及名称/正文重叠结果合理参与合并且不重复。当前目录补查区分普通条数截断与真实预算耗尽，保留绝对目录边界；受限结果明确提示缩小范围。

## 结果与文件动作可靠性

切换查询、类型、位置、排序或当前目录后，旧行与延后的菜单、媒体回调不能继续操作文件。当前请求已返回的有效首批仍可使用，不必等待全部正文完成。暂停索引的根仍可检索和操作留存结果。

在线且路径存在的云占位文件可定位、显式打开；右键 Copy/Cut、复制到、移动到和中转站继续按原有 URL/文件流程处理，不因预览正文不可用而失效。⌘C 与预览栏复制保留既有本地内容门禁；预览和播放不隐式下载占位正文。

## 筛选、位置与预览体验

筛选条件可单独移除，重置保留搜索词和视图偏好。短位置显示父目录与磁盘，离线、原文不可预览、提取失败和部分内容分别提示。默认跟随系统外观，可选深色毛玻璃；首批与完成耗时分开。窄 PDF 在布局完成或尺寸变化后定位命中选区。

## 索引、配置与验证

沿用唯一索引宿主、名称映射缓存、双只读查询连接、可见性门控、通知合并和关窗释放。不迁移 schema 或正文格式，不重建索引，不改变扫描/提取/写入/调度/范围，不启用暂停的语义实验。升级保全检查覆盖现有索引、根与排除目录、配置、会话和使用历史；停写替换与重启后的正常更新分开记录。

- 主包 Core 240 项，4 项条件跳过；内置 Core 140 项，1 项条件跳过，均无失败。
- 编码、PDF 页码与质量定向 24 项；正文候选/排序/摘要期限/真实取消质量回归 9 项。
- Debug 实际嵌入模型 147 项：包含暂停根、云占位条件、私有剪贴板、回调与拒绝路径、650 项目录干扰，以及 PDF/QL 释放和定位。
- 最终 Release、签名、DMG 与实际安装状态由对应交付记录提供。

每次 Core 相关度正文调用最多 4,000 候选，候选解压预算 48 MiB、含所选摘要 64 MiB，总期限 2 秒；当前目录多轮补查可能执行多次调用。这些是隔离夹具验证的阶段预算，不是应用全场景耗时保证。未做生产全盘排名或长期 CPU/RSS 对照，不宣称全面提速。云占位回归使用真实临时路径与拒绝本地正文的隔离 provider，未操作真实云文件；macOS 15 实机和另一台 Mac 首次 Gatekeeper 授权未在本轮验证。

## 下载与校验

适用于 macOS 15+、Apple Silicon（arm64）。公开 DMG 沿用 ad-hoc 签名，未经过 Apple 公证；本机更新保留既有本地签名身份。

[Wumi-1.2.6-arm64.dmg](https://github.com/kbwumin13-sudo/Wumi/releases/download/v1.2.6/Wumi-1.2.6-arm64.dmg) · [SHA256SUMS.txt](https://github.com/kbwumin13-sudo/Wumi/releases/download/v1.2.6/SHA256SUMS.txt) · [Release](https://github.com/kbwumin13-sudo/Wumi/releases/tag/v1.2.6)

下载 DMG 与校验文件到同一目录，运行：

    shasum -a 256 -c SHA256SUMS.txt

打开 DMG，将 Wumi.app 拖到 Applications。若 Gatekeeper 拦截，核对来源后按系统“隐私与安全性”提示处理，参阅 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。
