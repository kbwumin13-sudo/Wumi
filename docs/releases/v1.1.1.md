# Wumi 1.1.1

Wumi 1.1.1 的首次 GitHub Release / DMG 分发，将已有版本提供为可直接安装的应用。本次分发没有新增功能代码。

## 下载与安装

| 项目 | 说明 |
| :--- | :--- |
| 版本标签 | `v1.1.1` |
| 安装包 | [Wumi-1.1.1-arm64.dmg](https://github.com/kbwumin13-sudo/Wumi/releases/download/v1.1.1/Wumi-1.1.1-arm64.dmg) |
| 平台 | macOS 15+、Apple Silicon（arm64） |
| 签名 | 仅 ad-hoc 签名，没有 Developer ID 签名，未经 Apple 公证 |

[本版本 Release 与附件](https://github.com/kbwumin13-sudo/Wumi/releases/tag/v1.1.1) · [最新 Release](https://github.com/kbwumin13-sudo/Wumi/releases/latest)

1. 打开 DMG，将 `Wumi.app` 拖到 `Applications`（应用程序）。
2. 从「应用程序」打开 Wumi。
3. 首次若被 Gatekeeper 拦截，前往「系统设置 → 隐私与安全性」，在此次拦截的提示处选择「仍要打开」，再按系统提示确认。

安装包未经过 Apple 公证，首次打开方式见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

访问桌面、文稿等受保护目录时，按系统提示授权；完全磁盘访问的引导在应用「设置 → 隐私与权限」中。

## 已有功能

- 多标签、多窗格、工作区保存与会话恢复，列表、图标、分栏和画廊四种视图。
- 文件夹与应用包的后台逻辑大小统计，列表、图标、检查器和简介使用一致口径，支持按大小排序与变更刷新。统计包含隐藏文件与包内容，不跟随软链接、不读取文件正文。
- 本地文件名索引、查询过滤、内容搜索与后台增量更新。
- Quick Look、超级预览、批量重命名、压缩解压、校验和、文件夹同步，以及常用文件操作的撤销。
- Git 状态、iCloud 传输徽标、书签与标签、文件暂存浮窗、PDF 与图片工具、深浅色外观及 10 种界面语言。

## 已知限制与验证范围

- 本次仅提供 arm64 安装包，不提供 Intel 版本；需要 macOS 15 或更新版本。
- 安装包仅 ad-hoc 签名，没有 Developer ID 签名或 Apple 公证，首次打开可能受 Gatekeeper 拦截。
- 大目录的首次大小统计需要时间；计算中显示进度，无权限项目显示不可用或 `≥` 已知下界。这里显示的是逻辑字节大小，可能与磁盘实际占用不同。
- 超大目录和「所有子文件」目前最多一次载入 10 万项；搜索索引有容量与资源限制，可见范围受系统权限影响，不能保证全盘覆盖。长期含索引的资源占用仍待验证。
- Pages、Keynote、Numbers 新建模板暂受限，所有设置与交互尚未逐项完成窗口验收。

既有 1.1.1 验收记录为 205 项 Core 测试、0 失败、4 项条件跳过，以及曾通过的 65 项窗口内回归。条件跳过涉及真实 iCloud、十万项目录、全盘爬取与百万条索引。本次 DMG 另外完成了干净源码 Release 重新构建、磁盘映像完整性与只读挂载检查，并从安装包复制出的隔离副本通过了 65 项窗口内回归。实际从互联网下载后首次 Gatekeeper 授权流程未在另一台 Mac 验证。

## SHA-256 校验文件

从本版本 Release 的附件（Assets）下载 DMG 与 [Wumi-1.1.1-arm64.dmg.sha256](https://github.com/kbwumin13-sudo/Wumi/releases/download/v1.1.1/Wumi-1.1.1-arm64.dmg.sha256)。在两份文件所在的目录运行：

```sh
shasum -a 256 -c Wumi-1.1.1-arm64.dmg.sha256
```

输出 `Wumi-1.1.1-arm64.dmg: OK` 表示下载内容与发布文件一致。

源码构建与开发说明见 [安装、构建与运行](https://github.com/kbwumin13-sudo/Wumi/blob/v1.1.1/docs/构建与运行.md)。
