# Wumi 1.3.0

## 外观与动效

- 更新侧栏、标签页、工具栏、路径栏、检查器、预览和浮动文件。支持 Liquid Glass 的系统使用原生材质。
- 列表只对少量行的插入和移除做差异动画。目录重新排序直接更新列表，避免在主线程为全量重排计算动画差异。
- 浮动文件从可见窗口开始执行进场动效。侧栏入口和中转站继续使用既有配置。

## 内置觅迹 1.4.0

- 沿用觅迹原版的搜索胶囊、分类按钮、应用网格、最近文件、剪贴板与预览布局。
- 继续使用 Wumi 的单一索引宿主和既有索引。应用、文件、剪贴板与全部搜索可通过 ⌘1、⌘2、⌘3、⌘0 切换。
- 剪贴板记录需手动开启，仅在进程会话中保存。Wumi 的高级布尔搜索和文件发送到中转站入口继续可用。

## 下载与校验

- [Apple Silicon 安装包](https://github.com/kbwumin13-sudo/Wumi/releases/download/v1.3.0/Wumi-1.3.0-arm64.dmg)
- [实际界面演示 MP4](https://github.com/kbwumin13-sudo/Wumi/releases/download/v1.3.0/Wumi-1.3.0-demo.mp4)

适用于 macOS 15 或更新版本。安装包采用 ad-hoc 签名，未经 Apple 公证。将安装包和同名 `.sha256` 文件放进同一个目录并运行：

```sh
shasum -a 256 -c Wumi-1.3.0-arm64.dmg.sha256
```
